# Sprint_7

Автотесты API для учебного сервиса Яндекс Самокат.

## Реализованные проверки

- Создание курьера
- Логин курьера
- Создание заказа
- Получение списка заказов

## Технологии

- Python
- Pytest
- Requests
- Allure

## Установка зависимостей

pip install -r requirements.txt

## Запуск тестов

pytest tests

## Создание результатов Allure

pytest tests --alluredir=allure_results

## Просмотр отчёта Allure

allure serve allure_results

## Известный дефект

Тест авторизации курьера без поля `password` падает.

Ожидаемый результат:
- статус-код `400`

Фактический результат:
- статус-код `504`

Тест оставлен падающим, так как он фиксирует несоответствие фактического поведения API требованиям
